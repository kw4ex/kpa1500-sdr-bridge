# KPA1500 SDR Bridge 2.40

**Windows only.** This program runs on Windows 10 and 11 only. The installer and helper files are Windows batch files and will not work on a Mac or Linux.

Connects an **Elecraft KPA1500** amplifier (and an optional **Telepost LP-100A**) to **Thetis**, Thetis HL2, SDR-VST3 or **NereusSDR**, with a FlexControl knob, a browser control panel and a small **Applet** window. Windows.

This replaces the older [KPA1500 Thetis Bridge](https://github.com/kw4ex/kpa1500-thetis-bridge/releases/latest). Run only one of the two; this one closes the other when it starts.

## How to download (no GitHub account needed)

Easiest way (installer):

1. Install **Python 3.8 or newer** from python.org if you don't have it (tick **Add Python to PATH**).
2. Look at the **Assets** list at the bottom of this page and click **Install_KPA1500_SDR_Bridge.bat**. Your browser saves it, normally in your **Downloads** folder (if it warns that the file may be harmful, choose Keep).
3. Double-click it. It asks a few short questions and installs into its own folder (suggested: `C:\RadioScripts`).

Alternative (all the files): click **KPA1500_SDR_Bridge_v2.40_files.zip** in Assets, right-click it in Downloads, **Extract All…**, then follow the README. 

**Do not click "Source code (zip)" or "Source code (tar.gz)"**. Those are for programmers.

Then follow the settings for your radio program (Thetis or NereusSDR) in the [README](https://github.com/kw4ex/kpa1500-sdr-bridge#readme). The full help with every setting is the `KPA1500_Bridge_Help.html` file in Assets; open it in your browser.

To go back to an older version, open the [Releases page](https://github.com/kw4ex/kpa1500-sdr-bridge/releases) and download that one.
