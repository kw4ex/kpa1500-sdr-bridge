# KPA1500 SDR Bridge 2.49

**Windows only.** This program runs on Windows 10 and 11 only. The installer and helper files are Windows batch files and will not work on a Mac or Linux.

Connects an **Elecraft KPA1500** amplifier (and an optional **Telepost LP-100A**) to **Thetis**, Thetis HL2, SDR-VST3 or **NereusSDR**, with a FlexControl knob, a browser control panel and a small **Applet** window. Windows.

This replaces the older [KPA1500 Thetis Bridge](https://github.com/kw4ex/kpa1500-thetis-bridge/releases/latest). Run only one of the two; this one closes the other when it starts.

## How to download (no GitHub account needed)

Easiest way (installer):

1. Install **Python 3.8 or newer** from python.org if you don't have it (tick **Add Python to PATH**).
2. Look at the **Assets** list at the bottom of this page and click **Install_KPA1500_SDR_Bridge.bat**. Your browser saves it, normally in your **Downloads** folder (if it warns that the file may be harmful, choose Keep).
3. Double-click it. It asks a few short questions and installs into its own folder (suggested: `C:\RadioScripts`). Installing over an older version is fine: the installer keeps your settings and backs up the old files.

Alternative (all the files): click **KPA1500_SDR_Bridge_v2.49_files.zip** in Assets, right-click it in Downloads, **Extract All…**, then follow the README.

**Do not click "Source code (zip)" or "Source code (tar.gz)"**. Those are for programmers.

## New in 2.49

- **Your own Thetis buttons.** Three new buttons open the **Help**, the **Settings** page and the **Applet**. Up to **8 Programs**: give a slot a label, a program and optional arguments, and a button starts it. A button carries only the slot number, so it can never start anything you did not put in a slot, and the slots can only be edited on the bridge computer.
- **Numbers.** Up to 6 settings with **- / +** buttons and up to 4 preset buttons, for example a maximum safe drive. A number can control the over-drive limit, the TUNE auto-stop time, or just hold a value you show in Thetis.
- **Custom containers.** Build up to 8 of your own Thetis windows from the amplifier buttons, the open buttons, your programs and your numbers, in the order you choose (Settings, Custom containers). Setup creates them as `KPA1500 Custom - name - KW4EX`; Undo removes them.
- **New Settings page.** A menu of sections on the left, with colour, and **Restart bridge** / **Stop bridge** buttons in its header.

## Also new since 2.44

- **Software key (2.45, amplifier firmware 3.07 or newer).** The bridge can key the amplifier by network command instead of the hardware KEY IN line. A bridge setting and a Thetis **KEY: SOFT / KEY: HW** button switch between the two. Both can be used together (the amplifier keys when either is active). A software key needs about 5 ms of lead before RF, so test it with a dummy load first; the Help explains the timing.
- **TUNE with software key (2.46).** With software key, Standby-on-Tune and the amplifier in OPERATE, the **bridge TUNE button** drops the software key, waits until the amplifier is in STANDBY, and only then starts the radio's tune carrier. (Thetis's own TUNE button reports the transmit first, so the amplifier can be in OPERATE for a moment; use the bridge TUNE button for the safe order.)
- **Drive-limit warning in Thetis (2.47, 2.48).** When the drive limit is set to Warn, the message (and "no antenna?") now replaces the first line of the Thetis windows.
- **Controls window (2.47, 2.48).** New optional **KEY** button, **Legacy** button style as the default, one short top line (`ON OPR  AMP 7.135 MHz  RX -91 dBm`), and a narrower Knob window with its connection (`on COM3`) in the top line.
- **No blank lines (2.48).** Setup now fits the height of every Thetis window to what it shows. Thetis gives every text line a full row, so warnings no longer add a line.
- **New optional KPA1500 Meters window (2.48).** A small window with a status line and the Fwd and SWR bars. Tick it in the Applet (Thetis windows) or answer Yes when Setup asks, then rebuild the windows.
- **Stale data.** The first line of each Thetis window goes blank if the bridge freezes or crashes, and shows `!! BRIDGE STOPPED !!` when it is closed normally.

**To update:** close Thetis and the bridge, run the new `Install_KPA1500_SDR_Bridge.bat` over the old one (keep your options), start the bridge, open the Applet and press **Rebuild Thetis windows** (or close Thetis and run `Setup_Thetis_Containers.bat`), then start Thetis.

The Mac and Linux installer (experimental, untested on a Mac) is in the `mac-linux` folder of the repository.

Then follow the settings for your radio program (Thetis or NereusSDR) in the [README](https://github.com/kw4ex/kpa1500-sdr-bridge#readme). The full help with every setting is the `KPA1500_Bridge_Help.html` file in Assets; open it in your browser. The **Install and User Guide** is the PDF in Assets.

To go back to an older version, open the [Releases page](https://github.com/kw4ex/kpa1500-sdr-bridge/releases) and download that one.
