# EXPERIMENTAL and UNTESTED: KPA1500 SDR Bridge for Mac and Linux (based on 2.43)

**This is a Pre-release. It has not been tried on a real Mac, Linux computer, KPA1500, LP-100A or radio.** It passed the program's self-test (265 of 265) and an install, start, stop and uninstall run on Linux with simulated equipment. **Windows users: use the release marked Latest instead.**

For **NereusSDR on a Mac or Linux** computer (a Raspberry Pi is Linux), or Thetis on another computer. Thetis windows are Windows-only and not included.

## How to get it
1. In the **Assets** list click **Install_KPA1500_SDR_Bridge.sh** (and **README_Mac_Linux.txt**). Do not click "Source code".
2. Open Terminal, type `bash ` (with a space), drag the `.sh` file into the window, press Enter.
3. Answer the questions; follow README_Mac_Linux.txt (NereusSDR settings, safe first test with `--dry-run`).
4. To remove everything: `uninstall_kpa1500_sdr_bridge.sh` in the install folder.

## Small fixes in the program for Mac/Linux
Stopping a running bridge on Linux without lsof; clean shutdown when the Terminal closes; serial names like /dev/serial/by-id/...; hardware-address lookup on newer Linux; a Mac and Linux section in the built-in Help. Windows behaviour is unchanged.
